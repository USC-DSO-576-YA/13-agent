# Skill: Analyze mistakes

1. Match each question to a concept in the supplied course materials.
2. Compare the student's actual answer with a verified solution or rubric. If none is supplied, derive and verify the expected answer against the materials; label unresolved cases unassessable.
3. Describe the observable mismatch before proposing its cause.
4. Distinguish conceptual misunderstanding, prerequisite gap, procedural slip, and ambiguous evidence. Allow multiple possible causes.
5. Give more weight to repeated, independent evidence than to a single error. Account for hints, copied solutions, and missing responses when those facts are known; never assume them.
6. Rank concepts by the strength of the evidence and the value of practicing them. State what new evidence would resolve uncertain diagnoses.

Output evidence-backed practice priorities, not unsupported mastery scores.
