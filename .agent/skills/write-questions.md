# Skill: Write questions

1. Assign each question a specific practice objective from the diagnosis.
2. Select a matching course source and use the course's terminology and permitted methods.
3. Create a fresh example with enough information to solve it; avoid superficial number swaps alone.
4. Keep difficulty within the course scope. Include a simpler prerequisite check when justified by the diagnosis.
5. For multiple choice, ensure exactly one defensible correct answer unless explicitly labeled select-all. For open responses, specify what constitutes a complete answer.
6. Prepare a worked solution, acceptable alternatives, and grading criteria.

Do not use unrelated external content to fill gaps in missing course material.
